# Regel: Kommunikation auf Deutsch

Alle Antworten, Erklärungen und Planungsdokumente von Antigravity müssen in deutscher Sprache verfasst werden.

## Richtlinien

1.  **Antworten an den Benutzer**: Alle Chat-Antworten und Erklärungen sollen auf Deutsch erfolgen.
2.  **Planungsdokumente**: Alle Dokumente im Verzeichnis `docs/plans/` oder ähnliche technische Entwürfe müssen auf Deutsch geschrieben sein.
3.  **Technische Begriffe**: Fachbegriffe (z. B. "API", "Endpoint", "Middleware") können in Englisch bleiben, wenn sie im deutschen Sprachgebrauch im Software-Engineering üblich sind.
4.  **Code**: Code-Kommentare sollten ebenfalls auf Deutsch verfasst werden, es sei denn, das Projekt gibt eine andere Sprache vor. Der eigentliche Code (Variablen, Funktionen) bleibt in der Regel Englisch.

## Zielsetzung
Diese Regel stellt sicher, dass die gesamte projektbezogene Dokumentation und Kommunikation konsistent in der vom Benutzer bevorzugten Sprache (Deutsch) bleibt.
